Wolfy

Браузер для Windows, macOS и Linux: блокировка трекеров, раздельные пространства, менеджер паролей, темы и живые обои.

Что такое Wolfy

Wolfy — настольный браузер на основе Electron. Он работает на вашем компьютере: закладки, история, пароли и настройки остаются у вас и не отправляются на серверы Wolfy. Статистику использования приложение не собирает.

Возможности

  • Блокировка трекеров и очистка меток в ссылках.
  • Пространства с раздельными куками и отдельным прокси (HTTP, HTTPS, SOCKS5).
  • Расширения из Chrome Web Store.
  • Менеджер паролей: пароли шифруются средствами вашей системы.
  • Темы и живые обои: готовые темы, свои цвета, картинки и видео, каталог анимированных обоев.
  • Wolfy search — поиск со своими категориями, быстрыми словами и подсказками; источником результатов можно выбрать DuckDuckGo, Google, Bing, Яндекс, Brave и другие.
  • Перенос данных из Chrome, Edge, Яндекс Браузера, Brave, Opera, Vivaldi и Firefox.
  • Синхронизация между компьютерами через выбранную вами папку (Google Диск, OneDrive, Dropbox) с шифрованием.
  • ИИ-помощник выключен, пока вы сами не укажете свой ключ.
  • Две страницы рядом, лунный режим для сайтов, режим чтения, автообновление.

Вход через Google

Wolfy позволяет войти в профиль с помощью аккаунта Google. Это нужно, чтобы у каждого человека на компьютере были свои закладки, история, пароли и настройки, и чтобы в чужой профиль нельзя было войти без доступа к его аккаунту Google.

Приложение запрашивает только базовые права (openid, email, profile) и получает от Google адрес почты, имя и идентификатор аккаунта. Пароль от Google Wolfy не видит: вход проходит на странице Google в вашем браузере.

Эти данные хранятся только на вашем компьютере, не продаются, не используются для рекламы и не передаются третьим лицам. Использование данных Google соответствует Google API Services User Data Policy, включая требования Limited Use. Подробности: политика конфиденциальности.
